# 🎹 Code2MIDI：用代码谱写旋律

## 💡 项目背景
这是我的跨界创意项目。作为一名AI专业学生和十年钢琴爱好者，我尝试用Python将代码逻辑转化为MIDI音乐，探索“技术与艺术”的融合。

## 🚀 功能特性
- [x] 文本映射：将输入的字符串（如 HELLO_WORLD）转化为旋律
- [x] 自动生成标准的 `.mid` 文件
- [ ] 未来计划：接入 GPT API 自动生成歌词与和弦

## 🛠️ 技术栈
- Python 3.x
- MIDIUtil (生成MIDI文件)

## 📦 如何运行 (本地)
1. 安装依赖：`pip install MIDIUtil`
2. 运行脚本：`python code2midi.py`
3. 打开生成的 `output.mid` 即可播放。
